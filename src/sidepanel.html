    아직 복사한 링크가 없습니다.

    목록 0 / 100

    설정

    Ctrl + Alt + C

    MakeHyperlink 사용법

    복사 하기

    • 선택한 텍스트 복사

      웹페이지에서 텍스트를 선택하고 설정한 단축키를 누르거나, 우클릭 메뉴의 ‘하이퍼링크 만들기’를 선택하세요.

      기본 단축키는 Ctrl + Alt + C입니다. 주소창이나 사이드 패널이 아닌 웹페이지에 포커스가 있어야 합니다.

    • 페이지 제목으로 복사

      선택한 텍스트 없이 실행하면 현재 탭의 제목과 주소를 복사합니다.

    • 기본 링크 복사

      링크를 우클릭하고 ‘이 링크를 하이퍼링크로 복사’를 선택하면 링크의 텍스트와 실제 연결 주소를 복사합니다.

    목록 관리

    최근 100개를 이 브라우저에 저장합니다. 왼쪽 연필 아이콘으로 표시 이름을 수정하고 확인 또는 Enter로 저장하세요. 취소 또는 Esc로 취소합니다. 이름을 바꾼 뒤 파란 복사 아이콘을 누르면 변경한 이름으로 복사됩니다. 주소와 기존 시간·목록 순서는 유지됩니다.

    빨간 휴지통 아이콘으로 개별 항목을 삭제하세요. ‘전체 삭제’는 모든 항목을 지우며 되돌릴 수 없습니다.

    단축키 설정

    설정의 초록 연필 아이콘을 누르고 Ctrl, Alt, Meta 중 하나 이상을 포함한 키 조합을 입력하세요. Esc로 취소할 수 있습니다.

    ‘단축키 사용’을 끄면 단축키 실행과 변경이 중단됩니다. 우클릭 메뉴와 목록의 복사 버튼은 계속 사용할 수 있습니다.

    동작 확인

    확장 아이콘에 초록 OK는 복사 성공, 빨강 ERR는 실패를 뜻합니다. 브라우저 내부 화면과 웹 스토어 등에서는 페이지 복사를 사용할 수 없습니다.
