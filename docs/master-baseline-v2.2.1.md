# 1차 안정 버전 — v2.2.1

선언일: **2026-11-08**

v2.2.1을 Chrome 웹 스토어 및 네이버 웨일 스토어 제출 기준으로 사용할 첫 번째 안정 버전으로 지정합니다. 이 문서는 v2.2.1의 최종 상태와 기준 소스·배포물을 보존하고 정리합니다. 안정 버전 지정과 실제 스토어 제출·게시 완료는 별개입니다.

## 이 차수에서 개선된 기능 및 주요 상태

- **네이버 웨일 스토어 호환성 확보**:
  - ZIP 아카이브 내부 파일 경로를 표준 슬래시(`/`)로 강제 통일하여 웨일 스토어의 `Malicious entry: icons\icon128.png` 차단 오류를 완전히 해결했습니다.
- **다국어(i18n) 지원**:
  - 한국어 및 영어 지원 (기본값: 영어, 로컬 스토리지에 사용자 설정 영구 보존).
  - 사이드 패널, 사용법(Help), 설정(Settings), 브라우저 컨텍스트 메뉴 전체 번역 지원.
- **설정 모달 및 단축키 관리 개선**:
  - 상단에 설정 모달을 추가하여 언어 변경 및 단축키 On/Off 스위치, 커스텀 키 녹화 기능 제공.
  - 단축키 Off 시 불필요한 이벤트 가로채기 방지 및 설정 닫힘 시 키 입력 녹화 안전 중단.
- **히스토리 타일 라벨 편집 및 정렬 안정화**:
  - 패널 내 히스토리 타일 텍스트 수정 기능(수정 후에도 기존 생성 시각 및 정렬 순서 보존).
  - 수정된 라벨로 즉시 재복사 기능 지원.
- **스토어 등록용 리소스 체계화**:
  - Chrome 웹 스토어 및 네이버 웨일 스토어 규격에 맞춘 에셋 관리 구조 확립.
