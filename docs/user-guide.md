# 유저 가이드

[README로 돌아가기](../README.md) · [개발자 가이드](developer-guide.md)

이 문서는 MakeHyperlink **2.0.2** 기준입니다.

## 설치

[Chrome 웹 스토어에서 MakeHyperlink 설치하기](https://chromewebstore.google.com/detail/ehocahnpgninljhgpapiibodllnhchme?utm_source=item-share-cb)

## 하이퍼링크 복사

### 텍스트를 선택한 경우

1. 일반 웹페이지에서 링크 이름으로 사용할 텍스트를 드래그합니다. 입력창이나 텍스트 영역 안의 선택한 글자도 사용할 수 있습니다.
2. `Ctrl + Alt + C`를 누르거나 우클릭 메뉴의 **하이퍼링크 만들기**를 선택합니다.
3. 초록색 `OK` 배지를 확인하고 원하는 앱에 붙여넣습니다.

단축키는 웹페이지에 포커스가 있을 때 사용하세요. 주소창이나 사이드 패널에 포커스가 있으면 웹페이지의 단축키 처리기가 입력을 받지 못합니다.

### 텍스트를 선택하지 않은 경우

같은 방법으로 실행하면 탭 제목을 링크 이름으로 사용합니다. 제목이 비어 있으면 URL 자체를 이름으로 사용합니다. 이 경우도 히스토리에 저장됩니다.

### 붙여넣기 형식

클립보드에는 두 형식이 함께 저장됩니다. 붙여넣는 앱과 입력 모드에 따라 결과가 달라집니다.

| 형식 | 예시 |
| --- | --- |
| HTML | `프로젝트 문서`라는 이름의 클릭 가능한 링크 |
| 일반 텍스트 | `[프로젝트 문서](https://example.com/docs)` |

서식 없는 텍스트 편집기에 Markdown 문자열이 붙는 것은 정상입니다. 클릭 가능한 링크가 필요하면 서식 있는 붙여넣기를 지원하는 편집 영역을 사용하세요.

### 결과 배지

| 배지 | 의미 |
| --- | --- |
| 초록색 `OK` | 클립보드 복사 성공 |
| 빨간색 `ERR` | 복사 또는 페이지 접근 실패 |

배지는 마지막 결과를 표시한 시점부터 **1초 뒤** 사라집니다. 표시 중 아이콘에 마우스를 올리면 설명을 확인할 수 있습니다. `OK`는 클립보드 복사 결과이며, 저장 공간 오류가 있으면 히스토리 저장은 별도로 실패할 수 있습니다.

페이지 안에 토스트 알림을 표시하지 않습니다.

## 사이드 패널

도구 모음의 MakeHyperlink 아이콘을 눌러 패널을 엽니다. 페이지를 보면서 패널을 열어둘 수 있으며, 새로 복사한 항목이 실시간으로 표시됩니다. 닫기는 브라우저가 제공하는 패널 닫기 버튼을 사용합니다.

Chrome의 패널 좌우 위치는 **설정 → 모양 → 사이드 패널**에서 선택합니다. 확장 프로그램 자체에는 좌우 위치 설정이 없습니다.

### 히스토리 관리

- **복사**: 해당 항목의 HTML 링크와 Markdown 텍스트를 다시 클립보드에 기록합니다.
- **주소 클릭**: 기록된 주소를 새 탭으로 엽니다.
- **삭제**: 해당 항목을 제거합니다.
- **전체 삭제**: 저장된 히스토리를 모두 제거합니다. 현재 되돌리기 기능은 없습니다.

히스토리는 최근 **100개**까지 저장합니다. 같은 텍스트와 URL을 다시 복사하면 기존 항목 대신 최신 시각으로 맨 위에 표시합니다. 한도를 넘으면 오래된 항목부터 빠집니다.

제목과 주소는 각각 한 줄로 줄여 표시합니다. 마우스를 올리면 전체 내용과 전체 복사 시각을 확인할 수 있습니다. 화면 상단은 고정되고 히스토리 목록만 스크롤됩니다.

기록은 이 확장 프로그램의 브라우저 로컬 저장소에 저장하며, 다른 기기로 동기화하거나 외부 서버에 전송하지 않습니다. 앱 전체 클립보드 기록을 수집하는 기능은 없으며 MakeHyperlink에서 복사한 항목만 기록합니다.

## 단축키 설정

1. 패널 상단의 **변경** 버튼을 누릅니다.
2. `Ctrl`, `Alt`, `Meta` 중 하나 이상과 다른 키를 함께 누릅니다. `Shift`와 일반 키만 누르는 조합은 저장하지 않습니다.
3. 저장 완료 안내와 변경된 단축키를 확인합니다.

취소하려면 **취소** 버튼 또는 `Esc`를 사용합니다. 브라우저나 운영체제가 먼저 처리하는 조합은 웹페이지에 전달되지 않을 수 있으므로 다른 조합을 사용하세요.

상단 **단축키** 스위치를 끄면 페이지 단축키만 비활성화됩니다. 우클릭 메뉴와 히스토리의 복사 버튼은 계속 사용할 수 있습니다.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 단축키에 아무 반응이 없음 | 단축키 스위치, 저장된 조합, 웹페이지 포커스를 확인합니다. 확장 프로그램과 웹페이지를 새로고침하고 우클릭 복사도 확인합니다. |
| 우클릭은 되는데 단축키는 안 됨 | 페이지를 새로고침하고 단축키 활성화·충돌 여부를 확인합니다. |
| `ERR` 배지가 표시됨 | 페이지 주소가 아래 제한 범위인지 확인합니다. 일반 웹페이지라면 확장 프로그램의 사이트 접근 설정도 확인합니다. |
| 링크가 Markdown 문자열로 붙음 | 붙여넣는 앱이나 입력 영역이 HTML 서식을 지원하는지 확인합니다. |
| 패널이 안 열림 | 브라우저의 Side Panel API 지원 여부와 확장 프로그램 관리 화면의 오류를 확인합니다. |
| 복사는 되지만 기록이 안 보임 | 패널을 다시 열고 히스토리 저장 실패 안내 또는 확장 프로그램 오류를 확인합니다. |

다음 페이지에서는 페이지 내 단축키 감지와 스크립트 주입을 지원하지 않습니다.

- 브라우저 내부 화면: `chrome://…`, `whale://…` 등
- 다른 확장 프로그램 화면: `chrome-extension://…`, `whale-extension://…` 등
- Chrome 웹 스토어

특히 `whale-extension://<확장앱 ID>/index.html`은 일반 웹페이지가 아닙니다. 연결된 원본 `https://…` 페이지가 있다면 그 페이지에서 실행하세요. `file://…` 페이지는 브라우저의 확장 프로그램 상세 설정에서 파일 URL 접근 허용이 필요할 수 있습니다.

문제를 제보할 때는 브라우저·버전, 페이지 주소 종류, 실행 방법, 배지 표시 여부, 확장 프로그램 오류 화면의 **실제 오류 문구**를 함께 전달하세요. 소스 코드만 복사하면 오류 원인을 확인하기 어렵습니다.
