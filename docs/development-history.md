# 개발 히스토리

하이퍼링크 복사·사이드 패널·설정·스토어 호환 등 제품의 기능 추가·개선·수정을 버전별로 기록합니다. 웹 스토어 제출 기준이 되는 안정 버전은 기능 변경이 없어도 지정 사실과 기준판 문서 링크를 남깁니다. 안정 버전 지정이 실제 스토어 제출·게시 완료를 뜻하지는 않습니다. 현재 사용법은 [사용자 가이드](user-guide.md), 구조와 구현은 [개발자 가이드](developer-guide.md)를 참고하세요.

안정 버전의 고정 배포물과 차수별 추가 기능은 각 기준판 문서에서 확인할 수 있습니다.

---

## v2.2.1 — 1차 마스터 (안정 버전)

- 웹 스토어(Chrome 웹 스토어 및 네이버 웨일 스토어) 제출 기준으로 사용할 1차 안정 버전으로 지정했습니다. [기준 소스·배포물과 기능 요약](master-baseline-v2.2.1.md)을 보존합니다.
- 네이버 웨일 스토어 배포 패키지 호환성을 위해 `build.ps1`의 압축 생성 로직을 `.NET ZipArchive` 기반으로 개선하여, 아카이브 내부 파일 경로를 표준 슬래시(`/`)로 강제 통일했습니다. (웨일 스토어의 `Malicious entry: icons\icon128.png` 차단 방지)
- 스토어 에셋 폴더 구조를 Chrome 웹 스토어와 Whale 스토어별로 체계화했습니다.

## v2.1.5

- 설정 창(Settings Dialog)을 신설하고 상단에 배치했습니다.
- 다국어(영어·한국어) 선택 기능을 추가하고 사용자 선택 언어를 로컬 저장소에 영구 보존하도록 했습니다.
- 사이드 패널 컨트롤, 사용법 안내, 설정 창, 우클릭 컨텍스트 메뉴를 모두 다국어로 번역 지원합니다.
- 단축키 설정 및 녹화 기능을 사이드 패널 상단에서 설정 창 내부로 이동하고, 창이 닫힐 때 녹화가 안전하게 종료되도록 개선했습니다.
- 스토어 프로모션 에셋을 Git 및 배포 패키지에서 제외하도록 정리했습니다.

## v2.1.4

- 사이드 패널 히스토리 타일 왼쪽의 연필 아이콘을 통해 저장된 링크의 표시 이름을 직접 편집할 수 있는 기능을 추가했습니다.
- 이름 수정 시 기존 고유 ID와 복사 시간, 타일 정렬 순서가 유지되도록 보존했습니다.
- 수정된 이름으로 즉시 재복사 시 편집된 라벨과 원본 URL이 클립보드에 반영되도록 했습니다.

## v2.1.3

- 사이드 패널 상단에 `?` 버튼으로 열 수 있는 인패널 사용법(Help) 모달을 추가했습니다.
- 복사 방법, 목록 관리, 단축키 설정, 결과 확인 방법을 브라우저 내에서 즉시 확인할 수 있습니다.
- 모달이 닫힌 뒤 이전 포커스 위치로 안전하게 복귀하도록 접근성을 개선했습니다.

## v2.1.2

- 사이드 패널 목록 레이아웃을 컴팩트한 2줄 타일 형태로 개편했습니다.
- 웹페이지 내 기존 링크 우클릭 시 "이 링크를 하이퍼링크로 복사" 메뉴를 추가하여 표시 텍스트와 링크 URL을 원클릭으로 복사할 수 있게 했습니다.

## v2.0.2

- 불필요한 `activeTab` 권한을 매니페스트에서 제거하여 보안 권한 요구사항을 최소화했습니다.

## v2.0.1

- 브라우저 사이드 패널(`sidePanel` API)을 도입하여 최근 복사한 100개의 하이퍼링크 히스토리를 로컬에 저장하고 실시간으로 관리할 수 있게 했습니다.
- HTML 형식과 Markdown 일반 텍스트를 클립보드에 동시 기록하여 다양한 대상 앱 지원을 강화했습니다.
- 결과 표시를 위한 초록색 `OK` / 빨간색 `ERR` 배지 피드백 시스템을 구축했습니다.
- 복사 시 웹페이지 DOM을 오염시키지 않는 무간섭(Zero-mutation) 복사 방식을 적용했습니다.

## v1.1.2 ~ v1.0.0

- 최초 릴리스 및 크로스 오리진 iframe 지원 강화.
- 구글 검색 입력창 등 다양한 입력 요소 내 선택 텍스트 복사 안정성 확보.
- 기본 단축키(`Ctrl + Alt + C`) 및 우클릭 컨텍스트 메뉴 기반 하이퍼링크 생성 기본 기능 완성.
