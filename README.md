# MakeHyperlink (메이크 하이퍼링크)

**MakeHyperlink**는 웹 브라우저에서 드래그한 텍스트를 현재 페이지의 URL과 연결된 하이퍼링크 형식으로 즉시 복사해 주는 크롬 확장 프로그램입니다. 이메일 작성, 문서 편집, 메신저 대화 중에 텍스트와 링크를 일일이 연결하는 번거로움을 줄여줍니다.

## 🚀 주요 기능

- **하이퍼링크 즉시 복사**: 텍스트를 선택하고 단축키를 누르면, 해당 텍스트가 현재 URL로 연결된 하이퍼링크(Rich Text/HTML)로 클립보드에 저장됩니다.
- **커스텀 단축키 지원**: 기본 `Ctrl + Alt + C` 외에도 사용자가 원하는 단축키 조합을 직접 설정할 수 있습니다.
- **컨텍스트 메뉴 제공**: 마우스 오른쪽 버튼 메뉴를 통해 선택한 텍스트를 하이퍼링크로 바로 만들 수 있습니다.
- **프리미엄 UI/UX**: 글래스모피즘(Glassmorphism) 스타일의 세련된 토스트 알림과 직관적인 설정 팝업을 제공합니다.
- **자동 복구 시스템**: 확장 프로그램 업데이트 직후에도 페이지 새로고침 없이 즉시 기능을 사용할 수 있도록 동적 스크립트 주입 로직이 적용되어 있습니다.

## 🛠 설치 방법

1. 이 저장소를 다운로드하거나 클론합니다.
2. 크롬 브라우저를 열고 주소창에 `chrome://extensions/`를 입력하여 이동합니다.
3. 오른쪽 상단의 **'개발자 모드'**를 활성화합니다.
4. **'압축해제된 확장 프로그램을 로드합니다'** 버튼을 클릭합니다.
5. 다운로드한 프로젝트 폴더(`makehyperlink`)를 선택합니다.

## 📖 사용 방법

1. 원하는 웹 페이지에서 텍스트를 마우스로 드래그하여 선택합니다.
2. 단축키 `Ctrl + Alt + C` (기본값)를 누르거나, 마우스 오른쪽 버튼을 클릭하여 **'하이퍼링크 만들기'** 메뉴를 선택합니다.
3. "하이퍼링크 복사 완료!"라는 토스트 알림이 뜨면 성공입니다.
4. 하이퍼링크를 지원하는 애플리케이션(Gmail, Notion, Outlook, Word 등)에 `Ctrl + V`로 붙여넣기 하세요.

## ⚙️ 설정 변경

- 확장 프로그램 아이콘을 클릭하여 설정 팝업을 엽니다.
- **변경하기** 버튼을 누른 후 새로운 키 조합을 입력하여 단축키를 커스터마이징할 수 있습니다.
- 기능을 잠시 끄고 싶다면 **'단축키 활성화'** 스위치를 이용하세요.

## 📁 프로젝트 구조

- `manifest.json`: 확장 프로그램 설정 및 권한 정의 (Manifest V3)
- `background.js`: 컨텍스트 메뉴 관리 및 동적 스크립트 주입 로직
- `content.js`: 텍스트 선택 감지, 하이퍼링크 생성 및 복사 로직
- `popup.html/js/css`: 단축키 설정 및 옵션 관리 UI
- `style.css`: 페이지 내 토스트 알림 디자인
- `icons/`: 확장 프로그램 아이콘 리소스
