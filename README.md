# MakeHyperlink (메이크 하이퍼링크)

**MakeHyperlink**는 웹 브라우저에서 선택한 텍스트를 현재 페이지의 URL과 연결된 하이퍼링크 형식으로 즉시 복사해 주는 크롬 확장 프로그램입니다. 선택한 텍스트가 없으면 탭 제목을 링크 이름으로 사용합니다. 이메일 작성, 문서 편집, 메신저 대화 중에 텍스트와 링크를 일일이 연결하는 번거로움을 줄여줍니다.

## 🚀 주요 기능

- **하이퍼링크 즉시 복사**: 텍스트를 선택하고 단축키를 누르면, 해당 텍스트가 현재 URL로 연결된 하이퍼링크(Rich Text/HTML)로 클립보드에 저장됩니다.
- **커스텀 단축키 지원**: 기본 `Ctrl + Alt + C` 외에도 사용자가 원하는 단축키 조합을 직접 설정할 수 있습니다.
- **컨텍스트 메뉴 제공**: 마우스 오른쪽 버튼 메뉴를 통해 선택한 텍스트를 하이퍼링크로 바로 만들 수 있습니다.
- **아이콘 배지 알림**: 복사 결과를 확장 아이콘에 표시합니다. 알림을 위해 페이지에 요소를 추가하거나 편집 내용을 변경하지 않습니다.
- **사이드 패널 히스토리**: 성공적으로 복사한 텍스트와 URL을 최근 100개까지 로컬에 저장합니다. 브라우저 사이드 패널에서 다시 복사하거나 개별·전체 삭제할 수 있습니다. 같은 텍스트와 URL을 다시 복사하면 맨 위로 갱신됩니다. 패널을 열어둔 상태에서 새 복사 결과가 실시간으로 반영됩니다.
- **자동 복구 시스템**: 확장 프로그램 업데이트 직후에도 페이지 새로고침 없이 즉시 기능을 사용할 수 있도록 동적 스크립트 주입 로직이 적용되어 있습니다.

## 🛠 설치 방법

1. 이 저장소를 다운로드하거나 클론합니다.
2. 크롬 브라우저를 열고 주소창에 `chrome://extensions/`를 입력하여 이동합니다.
3. 오른쪽 상단의 **'개발자 모드'**를 활성화합니다.
4. **'압축해제된 확장 프로그램을 로드합니다'** 버튼을 클릭합니다.
5. 다운로드한 프로젝트 폴더(`makehyperlink`)를 선택합니다.

Chrome 114 이상이 필요합니다.

`chrome://`, `whale://`, `chrome-extension://`, `whale-extension://` 등 브라우저 내부·다른 확장 프로그램 화면과 웹 스토어에서는 콘텐츠 스크립트를 실행할 수 없어 페이지 내 단축키·우클릭 복사를 지원하지 않습니다. 해당 화면에 연결된 원본 웹페이지에서 실행하세요.

## 📖 사용 방법

1. 원하는 웹 페이지에서 텍스트를 선택합니다. 선택 없이 실행하면 탭 제목과 주소를 복사하며, 제목도 없으면 주소를 링크 이름으로 사용합니다.
2. 단축키 `Ctrl + Alt + C` (기본값)를 누르거나, 마우스 오른쪽 버튼을 클릭하여 **'하이퍼링크 만들기'** 메뉴를 선택합니다.
3. 확장 아이콘에 초록색 `OK` 배지가 표시되면 성공입니다. 빨간색 `ERR`은 복사 실패를 뜻합니다. 아이콘에 마우스를 올리면 결과 설명을 볼 수 있습니다. 배지는 마지막 결과 표시 후 1초 뒤 사라집니다. 아이콘은 Chrome의 확장 프로그램 메뉴에서 도구 모음에 고정하세요.
4. 하이퍼링크를 지원하는 애플리케이션(Gmail, Notion, Outlook, Word 등)에 `Ctrl + V`로 붙여넣기 하세요.

## ⚙️ 설정 변경

- 확장 프로그램 아이콘을 클릭하여 사이드 패널을 엽니다. 탭을 바꾸거나 페이지로 돌아가도 패널을 열어둘 수 있습니다.
- **변경** 버튼을 누른 후 새로운 키 조합을 입력하여 단축키를 커스터마이징할 수 있습니다.
- 기능을 잠시 끄고 싶다면 **'단축키 활성화'** 스위치를 이용하세요.
- 패널의 **히스토리**에서 항목별 **복사** 버튼을 누르면 HTML 하이퍼링크와 Markdown 텍스트를 다시 복사합니다. 긴 제목과 주소는 한 줄로 표시되며 마우스를 올리면 전체 내용을 볼 수 있습니다.
- 히스토리의 주소를 클릭하면 해당 페이지가 새 탭으로 열립니다.
- 패널의 좌우 위치는 Chrome **설정 → 모양 → 사이드 패널**에서 변경합니다.

## 📁 프로젝트 구조

- `manifest.json`: 확장 프로그램 설정 및 권한 정의 (Manifest V3)
- `background.js`: 컨텍스트 메뉴, 탭별 결과 배지 및 동적 스크립트 주입 로직
- `content.js`: 텍스트 선택 감지, 하이퍼링크 생성 및 복사 로직
- `sidepanel.html/js/css`: 브라우저 사이드 패널과 단축키 설정 UI
- `history.js`: 히스토리 표시, 링크 이동, 다시 복사 및 삭제
- `icons/`: 확장 프로그램 아이콘 리소스
